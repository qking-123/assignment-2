1. Project OverviewThis project aims to learn the unknown probability density function (PDF) of a transformed random variable $z$ using a Generative Adversarial Network (GAN). The methodology relies solely on data samples without assuming any parametric form (like Gaussian or Exponential) for the underlying distribution.2. MethodologyStep 1: Data TransformationThe feature $x$ ($NO_2$ concentration) was transformed into a new variable $z$ using a non-linear function derived from the University Roll Number.Transformation Function:$$z = x + a_r \cdot \sin(b_r \cdot x)$$Parameters Derived from Roll Number:Roll Number ($r$): 102483083Parameter $a_r$: $0.5 \times (102483083 \mod 7) = 0.5 \times 3 = \mathbf{1.5}$ Parameter $b_r$: $0.3 \times ((102483083 \mod 5) + 1) = 0.3 \times (3 + 1) = \mathbf{1.2}$ Step 2: GAN ArchitectureA standard GAN was implemented using PyTorch with the following architecture:Generator ($G$):Input: Noise vector of dimension 100.Hidden Layers: Three fully connected layers (256, 512, 256 units).Regularization: Batch Normalization and Dropout (0.3) applied after each hidden layer to prevent mode collapse.Activation: LeakyReLU (0.2) for hidden layers; Linear activation for the output layer.Discriminator ($D$):Input: Single scalar value $z$.Hidden Layers: Three fully connected layers (256, 512, 256 units).Regularization: Dropout (0.3) applied to stabilize training.Activation: LeakyReLU (0.2) for hidden layers; Sigmoid for the output layer.Step 3: Training ConfigurationLoss Function: Binary Cross Entropy (BCELoss).Optimizer: Adam ($\alpha=0.0002$, $\beta_1=0.5$).Epochs: 10,000.Batch Size: 128.3.
